## 2026-03-03 - [Chainable Drizzle Database Mocking in Vitest]
**Learning:** To mock nested, chainable Drizzle ORM queries (such as those used in `getUserStats` and `getUserSessions`) in Vitest unit testing, the database instance mock itself must NOT be thenable (Promise-like), while the query builder chain methods (like select/where/limit) must return thenable objects. If the database instance itself is thenable, async wrappers like `await getDb()` will prematurely resolve it, resulting in a runtime `TypeError` when chain-calling query builder methods.
**Action:** Always verify that mock database objects set via `setDb` do not export a `then` method, and implement a custom query builder mock returning chainable mock methods with a `.then` implementation resolving to custom mock arrays.
